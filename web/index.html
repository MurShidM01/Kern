What's new in v1.0.4

Installs finish, projects are folders, and every change is a diff.

The release that removed the command timeout — and the half-configured packages it left behind — and turned the agent's work into something you can read.

Nothing kills your installs

The timeout is gone. apt, npm and a cold build run until they exit instead of being killed at sixty seconds — which is exactly what left dpkg half-configured. Anything slow can also run as a background job while you keep working.

Projects are real folders

Create a project from Home and it becomes a directory named after itself. Inside the Linux environment they are all siblings under /workspace, so ls /workspace lists the same projects Home does.

Read the change, not the tool call

Every edit shows green added lines and red removed ones — in the approval sheet and in the transcript row. Models are fetched with one tap, and a permission change now applies to the turn that is already running.

Capabilities

Everything a mobile dev environment needs, and nothing it does not.

Kern is built around one idea: the model should be able to do the work, not just describe it. Every feature below exists to make that possible on a phone.

A real Linux, unrooted

A SHA-256-verified proot runtime installs Ubuntu 24.04.1 LTS on demand. You get a genuine bash, real apt and a real toolchain, driven by a hand-written POSIX PTY in C and a pure-Kotlin VT emulator.

Twenty-nine agent tools

Files, edits, builds, tests, Git, shell commands, dev servers, previews, plans and memory. Read-only calls run in parallel, mutating ones run in sequence behind your approval.

Nothing destructive runs silently

Every command is classified before it runs. rm -rf, mkfs and git reset --hard always ask, every time. Permission modes decide the rest, and secrets are redacted from every log.

Live preview of what it built

Start a dev server from the agent and a WebView preview opens with a browser-style console drawer. The agent reads that console, runs JavaScript in the page and captures screenshots.

Your keys never leave the device

API keys are encrypted with AES-256-GCM through the Android Keystore. Point Kern at a local model and nothing leaves your network at all.

Works with any OpenAI-compatible model

OpenAI, OpenRouter, Together, Groq, vLLM, Ollama, llama.cpp or your own gateway. Bring your own key and pick the model the agent uses.

A file explorer and editor

Browse the workspace, search across it and edit files with a line-numbered editor, all against the same tree the terminal uses.

A real package manager

Search the full apt index, install and remove packages inside the guest, and watch the output stream in a dedicated log screen.

Built to be looked at

Eleven colour palettes, light and dark, Material 3 dynamic colour and seven terminal themes including a 24-bit truecolour palette.

Use cases

What people actually do with it.

Learn Linux properly

A real shell, a real package manager, and an agent that can actually run what it explains to you.

Review code anywhere

Open a project folder, ask for a summary, then fix the thing that bothers you before you get home.

Test your web app on the move

Start the dev server, open the preview, read the console. No laptop in the loop.

Run scripts and automation

A quick Python script, a build you kicked off, a cron-style job that keeps running in the background.

Work without leaving a trace

Point Kern at a model on your own machine and nothing, not even a prompt, leaves your network.

Emergency shell access

A working bash on a device with no monitor, no keyboard and no root.
